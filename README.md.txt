# 🛍️ Collection Store — E-commerce Website

A modern and responsive frontend e-commerce website designed to provide a smooth and engaging online shopping experience.

## 🚀 About The Project

Collection Store is a frontend e-commerce website built to showcase products through an attractive and user-friendly shopping interface.

This project focuses on creating a clean layout, responsive design, and an enjoyable browsing experience for users.

## ✨ Features

 🏠 Attractive homepage
 🛍️ Product browsing interface
 📦 Product categories
 🎨 Modern and responsive UI
 📱 Mobile-friendly design
 ⚡ Interactive frontend experience

## 🛠️ Technologies Used

 HTML5
 CSS3
 JavaScript
